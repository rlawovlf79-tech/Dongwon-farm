# 동원농원 브랜드 가이드

동원농원 콘텐츠를 만들 때 이 문서의 규칙이 다른 기본값보다 우선한다.
사장님이 대화에서 직접 다르게 말하면 그 말을 따른다.

## 1. 절대 규칙

1. **AI로 만든 이미지·영상은 쓰지 않는다.** 사과, 사람, 배경, 장식 모두 해당한다.
   - Canva 자동 생성 디자인에 들어간 이미지 요소(장식 박스, 그라데이션, 아이콘 이미지 포함)는 지우고, 실제 사진과 Canva 기본 도형·글자로 다시 만든다.
   - 스톡 사진도 쓰지 않는다. 사장님이 보낸 사진·영상만 쓴다.
2. **확인하지 않은 사실은 쓰지 않는다.** 당도(브릭스), 가격, 할인율, 수확량, 수상 경력, "무농약" 같은 표현은 사장님이 말해준 경우에만 쓴다.
   - 팔로워 혜택은 내용이 정해지기 전까지 "팔로워 특별 혜택"으로만 쓴다.
3. **남의 영상·음악·디자인을 그대로 베끼지 않는다.** 참고 영상은 구성, 컷 길이, 자막 스타일만 따라 하고, 화면은 동원농원 실제 촬영분으로 채운다.
4. **전화번호·주소는 사장님이 공개한 것만 쓴다.** 현재 공개 번호: 010-3473-9110. 농원 간판 사진(8페이지)에는 예전 번호 010-3472-9110이 보이므로, 간판 사진을 쓸 때는 사장님께 확인한다.

## 3. 말투

- 농부가 직접 이야기하는 느낌으로 쓴다. 광고 문구처럼 쓰지 않는다.
- 짧은 문장으로 쓴다. 한 문장에 하나만 말한다.
- 존댓말을 쓰되 딱딱하지 않게 쓴다. ("~했어요", "~드릴게요")
- 그날 실제로 한 일을 쓴다. ("오늘은 아랫밭 부사 땄어요", "새벽에 서리 내려서 해 뜨고 시작했어요")
- 이모지는 문단마다 0~1개만 쓴다. 🍎 정도면 충분하다.

**쓰지 않는 표현**
- "최고의", "프리미엄", "명품", "역대급", "인생 사과"
- "~를 경험해 보세요", "놓치지 마세요", "지금 바로!" 같은 광고 말투
- 이모지를 줄줄이 붙이기, 느낌표 연달아 쓰기
- 근거 없는 숫자 ("당도 16브릭스", "500박스 완판")

## 4. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 사과 빨강 | `#D6242C` | 강조 박스, 마무리 화면 배경, 전화번호 글자 |
| 흰색 | `#FFFFFF` | 큰 제목 글자, 전화번호 버튼 |
| 크림 | `#FFF1E0` | 작은 손글씨 문구, 보조 문구 |
| 짙은 밤색 | `#140A06` | 하단 어둡게 하는 층(투명도 12~18%를 여러 겹), 상단 라벨 배경(투명도 45%) |

빨강은 화면마다 한 곳에만 크게 쓴다.

## 5. 글씨체

| 역할 | 글씨체 | 비고 |
|---|---|---|
| 큰 제목, 강조 | Black Han Sans | 굵고 짧게, 7자 안쪽 |
| 작은 감성 문구 | 나눔손글씨 펜 | "2026 가을, 예산" 같은 한 줄 |
| 정보·연락처 | 나눔고딕 ExtraBold | 전화번호, 주문 안내 |

- 글씨체 파일은 Google Fonts에서 받는다 (`google/fonts` 저장소의 `ofl/blackhansans`, `ofl/nanumpenscript`, `ofl/nanumgothic`).
- Black Han Sans에는 가운뎃점(·)이 없다. 제목에는 `·` 대신 `!`나 띄어쓰기를 쓴다.

## 6. 화면 구성 (세로 1080×1920)

- **배경**: 실제 사진을 화면 가득 채운다.
- **상단 왼쪽**: 작은 라벨 "동원농원 | 예산 사과".
- **하단 자막 묶음**: 손글씨 한 줄 → 큰 제목 한 줄 → 빨간 박스 안 강조 한 줄.
- **자막 위치**: 인스타 하단 버튼과 캡션에 가리지 않도록 화면 아래 끝에서 약 300px 위까지만 쓴다. 오른쪽 끝 150px도 비워 둔다.
- **하단 어둡게**: 글자가 잘 보이도록 아래쪽만 어둡게 한다. 경계가 보이지 않게 여러 겹으로 부드럽게 겹친다.
- **마무리 화면**: 빨간 배경에 "나무에서 따자마자 / 바로 포장! 바로 발송! / 동원농원 / 010-3473-9110 / 팔로우하고 혜택 받기".

## 7. 릴스 구성

- 길이는 15~25초.
- 첫 2초 안에 핵심을 보여준다. 가장 먹음직스러운 사과 클로즈업 + "지금 동원농원은 수확 중".
- 장면당 2.5~3초. 장면이 바뀔 때는 짧게 겹쳐 넘긴다 (0.4초 정도).
- 순서: 사과 클로즈업 → 나무 → 따는 손·사람 → 선별·포장 → 박스 → 농원 간판 → 연락처.
- 사진 대신 직접 찍은 짧은 영상 클립이 있으면 클립을 먼저 쓴다. 따는 소리, 박스 접는 소리 같은 현장 소리는 살린다.
- 음악은 넣지 않고 무음 트랙으로 내보낸다. 사장님이 인스타에서 인기 음원을 직접 고른다.

영상 제작 스크립트: `reels/make_reels.py` (사진 폴더, 글씨체 폴더, 출력 파일을 인자로 받는다).

## 8. 글 형식

### 인스타 캡션
1. 첫 줄: 지금 상황 한 줄 ("🍎 지금, 동원농원은 수확 중입니다")
2. 본문 2~4줄: 오늘 실제로 한 일
3. 판매 안내: ✔️ 로 2~3줄 (A급 빨간 박스 / 가정용 / 바로 발송)
4. 혜택·다음 영상 예고 한 줄
5. 연락처: "📞 주문·문의 010-3473-9110 / DM"
6. 해시태그 15~25개, 본문과 한 줄 띄운다.

### 스레드
- 3~5줄로 짧게, 대화하듯 쓴다.
- 판매 정보는 본글에 넣지 않고 이어지는 글(답글)로 뺀다.
- 가끔 질문으로 끝낸다. ("사과는 아삭한 거 vs 달달한 거?")

## 9. Canva 작업 순서

1. 사장님 사진을 Canva에 올린다 (`create-upload-url` → 파일 원본 그대로 POST). MP4는 이 경로로 올라가지 않는다.
2. 디자인을 생성하면 페이지마다 확인한다:
   - 배경을 실제 사진으로 바꾼다.
   - 이미지로 채워진 요소(`fill.media`가 있는 사각형)는 모두 지우고, 기본 도형(`insert_shape`)으로 다시 그린다.
   - 글자를 도형 위로 올린다 (`layer_element` front).
3. Canva가 만든 글자에 오타가 자주 생긴다. 한 글자씩 확인한다. (지난번 예: 굴사과→꿀사과, 선물서트→선물세트, 동원뇽원→동원농원)
4. 미리보기를 사장님께 보여주고 "저장" 답을 받은 뒤에만 저장한다.

## 10. 내보내기 전 확인

- [ ] AI 이미지나 Canva 자동 생성 이미지 요소가 하나도 없는가
- [ ] 모든 사진이 사장님이 보낸 실제 사진인가
- [ ] 확인하지 않은 숫자·주장이 없는가
- [ ] 오타가 없는가 (특히 농원 이름, 전화번호)
- [ ] 자막이 인스타 하단 UI에 가리지 않는가
- [ ] 광고 말투나 쓰지 않는 표현이 없는가
